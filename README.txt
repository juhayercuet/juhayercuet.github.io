UPDATE YOUR GITHUB WEBSITE
All files are in ONE folder (no "img" subfolder), so the photos always load.
1. Open your repository: github.com/<username>/<username>.github.io
2. Add file > Upload files. Drag in ALL files from this folder (index.html + all .jpg photos).
   Files with the same name are replaced automatically. Click "Commit changes".
3. Wait 1-2 minutes, then open your site and press Ctrl+F5 (or pull down to refresh on phone).
